# 3D京都駅構内図
## 概要
このアプリは京都駅の駅構内図を立体的に見ることができるアプリです。  
自由に移動・回転・ズームすることで好きな場所、角度から見ることができます。  
JRだけでなく、近鉄京都駅や京都市営地下鉄の駅も含まれています。

## 使用方法
1. https://github.com/ha9913570/3DKyotoStation/releases から最新版のZipファイルをダウンロード
2. ダウンロードしたZipファイルを解凍
3. 3DKyotoStation.exeを起動

## 仕様技術
- Unity 6.3
- C#

## 主な機能
- 特定の階だけを強調表示
- マウスとキーボードを用いた移動・回転・ズーム
- 改札口、トイレ、コンビニの位置を表示
