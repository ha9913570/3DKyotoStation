# プロジェクトルール
## 命名規則
これらは全てパスカルケース(PascalCase)で記述する。
- ディレクトリ名
- ファイル名
- クラス名
- 関数名

これらは全てキャメルケース(camelCase)で記述する。
- 変数名

これらは全てアッパースネークケース(UPPER_SNAKE_CASE)で記述する。
- 定数名

## ディレクトリ構造
- Assets
  - 各種リソース
- Docs
  - ドキュメント
- Assets/Images
  - 画像ファイル
- Assets/Models
  - 3Dモデル(fbx形式)
- Assets/Prefabs
  - プレハブ
- Assets/Resources
  - フォントファイル
- Assets/Scenes
  - Unityシーン
- Assets/Scripts
  - C#ファイル
